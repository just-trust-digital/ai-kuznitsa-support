# ИИ ассистент поддержки

Конкурсный стенд поддержки клиентов магазина ПО. Помощник отвечает по каталогу и справке, уточняет условия запроса и передаёт обращения менеджеру. Учебные заказы, профили и документы вымышлены.

## Запуск

Откройте PowerShell в корне клонированного репозитория. Понадобится Python 3.12.

```powershell
.\Start-Support.ps1
```

Откройте [локальный стенд](http://127.0.0.1:8766/?utm_source=jtd_dev). Войдите гостем или скопируйте токен жюри из второго окна PowerShell в той же папке:

```powershell
.\Start-Support.ps1 -CopyToken jury
```

Токен создаётся при первом запуске и хранится локально в `private/runtime/access.json`. Основной стенд и предпросмотр используют этот файл. Остановить стенд можно клавишами Ctrl+C.

## Что показать

1. Войдите как жюри и выберите роль «Клиент», «Гость», «Менеджер 1» или «Менеджер 2».
2. В каталоге раскройте «О товаре» и отправьте в чат «Сколько стоит?». Помощник учтёт выделенную позицию. На вкладке «Корзина» спросите «Сколько стоит корзина?». Добавляйте позиции из каталога, удаляйте их в корзине.
3. В роли клиента откройте заказы, лицензии и документы своего профиля. Смените вымышленный профиль через «Настроить сессию».
4. В чате попросите подключить менеджера, затем откройте очередь под ролью менеджера. В «Обучении» можно проверить ответы, а в «Журнале» посмотреть число передач. Под спойлером в настройках клиента можно переключить версию каталога и сверить изменение цены.

Для чистого запуска включены небольшой каталог и сценарные ответы. Подключённые модели могут дополнять консультации. Цены, права, выдачу документов и передачу менеджеру определяет сервер. Чаты, учебные документы и оценки сохраняются локально в SQLite. Используйте вымышленные сведения.

## Проверка и архитектура

```powershell
python -X utf8 -m unittest discover -s tests
```

Интерфейс использует HTML, CSS и JavaScript. Сервер, хранилище и проверки запускаются на стандартной библиотеке Python. Серверный каталог поставляет цены и доступность. В режиме правил запуск работает без модели и внешних сервисов. Для сценарного ответа запросы к моделям равны нулю. Полная стоимость зависит от хоста и работы менеджера. Порядок изменений в коде описан в [карте для агентов](docs/agent-routing.md).
